# Starter Script

`hello.sh` is a starter template for Activity 9. The task requires a script that prints the exact greeting `Hello, Linux World!`, the current date/time using `date`, and the current working directory using `pwd`.

The task does not prescribe the script's location. The workflow places it at `linux_lab/scripts/hello.sh` so it uses the `scripts` directory created in Activity 1.

From inside `linux_lab`, copy the starter template if desired:

```bash
cp /path/to/this/repository/scripts/hello.sh scripts/hello.sh
chmod +x scripts/hello.sh
./scripts/hello.sh
```

Replace `/path/to/this/repository` with the actual location of the extracted project. Alternatively, create/edit the file directly with `nano scripts/hello.sh`.

This is a simple learning script; it does not modify system configuration.
