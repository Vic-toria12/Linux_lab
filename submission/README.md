# Submission Preparation

## What the supplied task requires

The uploaded task sheet describes ten practical activities. It does **not** specify:
- where to submit the work;
- whether the submission must be a ZIP, PDF, Word document, or GitHub link;
- a required screenshot count or naming convention;
- whether command history or terminal-output files are mandatory.

Confirm those details with your instructor. Do not assume the optional evidence structure in this repository is a formal task requirement.

## Prepare your own submission

1. Complete all ten activities in the Linux environment.
2. Save actual command history if requested.
3. Save actual terminal output or screenshots only if requested.
4. Review the final verification checklist in the root `README.md`.
5. Remove or redact sensitive system information before publishing publicly.
6. Submit using the instructor's stated method.

## Included templates

- `command-history.txt`: paste your real command history if requested.
- `final-output.txt`: record actual final checks, notes, and any environment limitations.

Do not fill these templates with invented outputs. If a step could not be completed because permissions, distribution, or network access prevented it, record that fact accurately.
