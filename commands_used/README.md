# Command Reference

`commands.sh` is a **print-only reference**. Running it displays the commands; it does not execute the lab. This is intentional because the practical includes interactive commands, system-wide changes, account administration, and package removal.

Copy and run commands individually in the order shown in `workflow/workflow.md`. Check each command before running it, especially `rm`, `chmod 777`, `chown`, APT operations, and changes to `/etc/hosts`.
